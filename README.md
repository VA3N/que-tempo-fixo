# Que tempo fixo

- 1. Descripción del Proyecto y de la Estación

Este proyecto consiste en el desarrollo de un pipeline reproducible de datos en Python para la ingesta, limpieza, análisis y almacenamiento relacional de las series temporales meteorológicas de la estación de A Coruña / Alvedro entre los años 2021 y 2025.

- Ficha Técnica de la Estación Meteorológica
* **Nombre de la estación:** A Coruña / Alvedro (Aeropuerto)
* **Indicativo:** 08002
* **Coordenadas:** Latitud 43.3000 N | Longitud -8.3833 W | Altitud 97 m

---

# 2. Fuente de los Datos
